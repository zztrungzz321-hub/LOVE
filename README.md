# Love confession page

Trang web tỏ tình đơn giản, chạy được trực tiếp trên GitHub Pages.

## Cách dùng

1. Upload toàn bộ thư mục này lên GitHub.
2. Vào Settings > Pages.
3. Chọn Branch: main, thư mục: /root.
4. Mở link được cung cấp.

## Tính năng

- Hiệu ứng hoa anh đào rơi
- Đếm ngược từ 10 về 0
- Tạo nhiều trái tim khi về 0
- Chữ I LOVE YOU hiện ra đẹp mắt
- Một vài hiệu ứng cute và sparkles
